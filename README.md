# 🦺 SafeVision — Real-Time PPE & Face Safety Detection

**SafeVision** is a deep-learning-based workplace safety monitoring system designed to detect PPE compliance from images, videos, and live webcam feeds.

The system combines **face-mask classification, PPE object detection, spatial compliance analysis, real-time video processing, tracking, alerts, and model explainability** into a single Streamlit application.

> **Important:** This repository contains the complete ML pipeline and application code, but does not include a pretrained PPE dataset or pretrained model weights. Real performance metrics must be generated by training and evaluating the models on real datasets.

---

## 🚀 Features

### 🤖 Machine Learning

- **Face Mask Classification**
  - Custom CNN trained from scratch
  - MobileNetV2 transfer learning
  - MobileNetV2 fine-tuning
  - Data augmentation
  - Class-imbalance handling
  - Early stopping and learning-rate scheduling

- **PPE Object Detection**
  - YOLOv8n using Ultralytics
  - Detects:
    - `person`
    - `helmet`
    - `mask`
    - `vest`
  - Supports additional negative classes when configured

- **PPE Compliance Engine**
  - Associates detected PPE with individual people
  - Generates:
    - `COMPLIANT`
    - `VIOLATION`

### 📊 Evaluation & Explainability

### 🎥 Real-Time Detection

# 🧠 Deep Learning Pipeline

## 1. Face Mask Classification

SafeVision provides two classification approaches.

### Custom CNN

```text
Input
  ↓
Rescaling
  ↓
Conv2D
  ↓
BatchNorm
  ↓
ReLU
  ↓
MaxPool
  ↓
Conv2D
  ↓
BatchNorm
  ↓
ReLU
  ↓
MaxPool
  ↓
Conv2D
  ↓
BatchNorm
  ↓
ReLU
  ↓
MaxPool
  ↓
Global Average Pooling
  ↓
Dense
  ↓
Dropout
  ↓
Softmax
  ↓
Mask / No Mask
```

### MobileNetV2

```text
Input
  ↓
MobileNetV2 preprocessing
  ↓
MobileNetV2
  ↓
Global Average Pooling
  ↓
Dropout
  ↓
Dense
  ↓
Mask / No Mask
```

MobileNetV2 is initially used with frozen ImageNet-based layers and is subsequently fine-tuned by unfreezing the upper layers with a lower learning rate.

# 🎯 2. PPE Detection

The PPE detection pipeline uses **Ultralytics YOLOv8n**.

```text
Input Image
     ↓
   YOLOv8n
     ↓
┌──────────────────────┐
│ Person               │
│ Helmet               │
│ Mask                 │
│ Vest                 │
└──────────────────────┘
     ↓
Bounding Boxes
     ↓
Compliance Engine
```

The detector is trained using a PPE dataset in YOLO format with a corresponding `data.yaml`.

---

# 👷 Compliance Detection

After YOLO detects people and PPE, SafeVision performs spatial association between PPE objects and detected people.

Example:

```text
Person #1
├── Helmet ✓
├── Mask   ✓
└── Vest   ✓

        ↓

    COMPLIANT
```

Violation example:

```text
Person #2
├── Helmet ✗
├── Mask   ✓
└── Vest   ✓

        ↓

    VIOLATION
```

The PPE-to-person association is heuristic and is based on bounding-box regions rather than a learned association model. Dense crowds and heavy occlusion can therefore affect association accuracy.

# 📦 Dataset Setup

SafeVision uses two different datasets.

## A. Face Mask Classification Dataset

Expected structure:

```text
data/
└── raw/
    └── mask_classification/
        ├── mask/
        └── no_mask/
```

The classifier preparation script creates the train/validation/test splits used by the training pipeline.

## B. PPE Detection Dataset

Expected structure:

```text
data/
└── raw/
    └── ppe_detection/
        ├── images/
        ├── labels/
        └── data.yaml
```

The PPE detector requires a YOLO-format labeled dataset.

> **Note:** No real dataset is bundled with this repository.

The repository documentation specifies the mask classification and PPE detection dataset locations separately.

# 🔧 Troubleshooting

### Dataset directory is missing

If you see:

```text
Dataset directory 'data\splits\train' is missing or empty
```

run:

```bash
python scripts/download_dataset.py --check
python scripts/prepare_dataset.py
```

Then retry training.

### Model weights not found

The model has not been trained yet.

Run the corresponding training command:

```bash
python scripts/train_classifier.py --model custom_cnn
```

or:

```bash
python scripts/train_classifier.py --model mobilenet
```

### YOLO detects people but not PPE

The PPE detector requires a trained PPE dataset/model.

Prepare the YOLO dataset and run:

```bash
python scripts/train_detector.py
```

### Webcam error

Make sure:

- A webcam is connected
- The operating system allows camera access
- Streamlit is running locally
- OpenCV can access the camera

### Slow CPU inference

Real-time performance depends on hardware. CPU-only systems may have lower FPS. The project uses YOLOv8n as the lightweight detector and supports reducing resolution/frame processing when necessary.

# 🔐 Privacy

SafeVision performs **PPE compliance detection**, not facial recognition or identity inference.

Tracking IDs are temporary and reset between sessions.

---

# ⚠️ Limitations

- PPE-to-person association is heuristic.
- Dense crowds and heavy occlusion can cause incorrect PPE association.
- Detection quality depends heavily on the PPE dataset used for training.
- No PPE detection dataset is included in the repository.
- Real-time FPS depends on available hardware.
- CPU-only systems may have slower inference.

These limitations are part of the documented system behavior.

Computer Vision

Object Detection
      +
Transfer Learning
      +
Explainable AI
